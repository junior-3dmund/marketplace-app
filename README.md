# Marketplace App

A simple marketplace web application inspired by Jumia and Tonaton.

## Features

- Product discovery and search
- Category filtering
- Sort by featured, latest, and price
- Product detail preview
- Seller contact CTA

## Setup

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open `http://localhost:4173`
